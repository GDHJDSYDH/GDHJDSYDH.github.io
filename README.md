## 如何新增下一款小游戏

1. 将新游戏的封面图放入 `assets/games/` 目录。
2. 打开 `data/games.js`，在 `window.GAMES` 数组中按现有格式追加一个游戏对象（填入中英文标题、简介、特色、操作说明及 GitHub Pages 游玩链接）。
3. 提交并推送至 `main` 分支，GitHub Pages 将自动更新上线。
